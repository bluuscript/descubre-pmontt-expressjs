## Estructura del Proyecto

```
descubre-pmontt-expressjs/
│
├── public/                  # Archivos estáticos
│   ├── css/                # Hojas de estilo (Bootstrap)
│   ├── img/                # Imágenes
│   └── js/                 # JavaScript frontend
│
├── src/
│   ├── config/             # Configuración de base de datos
│   ├── model/              # Modelos de datos
│   ├── routes/             # Rutas de la API
│   └── app.js              # Configuración principal de Express
│
├── views/                  # Vistas EJS
│   ├── index.ejs           # Página principal
│   └── app/
│       └── panel.ejs       # Panel de usuario
│
├── .env                    # Variables de entorno
├── package.json            # Dependencias del proyecto
└── server.js               # Punto de inicio
```

## Cómo abrir
1. Descomprimir el ZIP.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir index.html.
4. Recomendado usar Live Server.

## Nota
Es un proyecto 100% Front-End. El login, registro y recuperación están simulados con LocalStorage.
